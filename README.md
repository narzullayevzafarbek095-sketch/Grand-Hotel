## 🚀 Ishga Tushirish

### 1-usul: Darhol Brauzerda Ishga Tushirish (Hech narsa o‘rnatmasdan)
Loyiha papkasidagi [`index.html`](file:///c:/Users/user/Desktop/HOTTEL/index.html) faylini sichqoncha bilan ikki marta bosing yoki Google Chrome / Microsoft Edge brauzerida oching. 100% tayyor va to‘liq ishlaydi!

### 2-usul: Full-Stack Rejimida Ishga Tushirish
```bash
# Server papkasida
cd server
npm install
npm start
# Server http://localhost:5000 da ishlaydi

# Client papkasida
cd ../client
npm install
npm run dev
# Frontend http://localhost:3000 da ochiladi
```
